# Closet da Eve - Bazar de Roupas de Marca

Site desenvolvido para o bazar de roupas de marca "Closet da Eve", oferecendo roupas, sapatos e bolsas de marcas exclusivas por preços acessíveis.

## Conteúdo

- Página inicial com destaque para os produtos principais
- Seção de produtos dividida por categorias (Roupas, Sapatos, Bolsas)
- Seção sobre a loja
- Formulário de contato
- Informações de localização e redes sociais

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome para ícones

## Hospedagem

Este site está hospedado no GitHub Pages.
